# 智能实验室预约系统

## 项目来源

这是对 FastAPI + Vue3 + Agent 的一个跟练项目

[课程视频地址](https://www.bilibili.com/video/BV13hbP6zEUd/)

[笔记文档地址](https://ai.codenice.cn/free/ai-smart-lab-booking)

## 技术栈

| 端 | 技术 |
|--|--|
|前端|	pnpm · Vue 3 · Vite · Element Plus · Axios|
|后端|	uv · Python · FastAPI · SQLAlchemy · JWT|
|数据库|	MySQL|
|AI|	LangChain · ChromaDB · RAG · Tool Calling · LangGraph · SSE|

## 额外补充内容

- 增加了 `cSpell` 进行单词拼写校验
- 保留了 `FastAPI` 项目及 `Vue3` 项目一些常用的 `vscode` 配置及拓展插件推荐
- 使用 `vscode` 的工作区实现前后端项目同时管理，并配置不同的解释器
